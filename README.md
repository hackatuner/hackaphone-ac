# AC Phone (HackaPhone)

iPhone-style phone app for Assetto Corsa (CSP Lua app) by hackatuner.

**Install:** download this repo (Code → Download ZIP) and copy the `ACPhone` folder into `assettocorsa/apps/lua/`.
After that, the phone updates itself whenever a new version is published here.

`update.json` is the update feed the phones read. Don't edit it by hand.
